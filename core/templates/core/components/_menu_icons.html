{% comment %} 菜单项的图标，一个名字一个图形（2026-09-14）。 🔴 **它们是给钉住之后那条窄栏用的。** 展开的面板上有字，图标只是陪衬；收成 4.5rem 的窄栏之后，图标加底下那行小字就是这一项的**全部** —— 所以每一个都要 在 20×20 的框里、不靠颜色、一眼分得出彼此。 ⚠️ 名字从 `core.context_processors._menu_for()` 来，而 `_link()` 把 `icon` 做成了 必填的位置参数：加一条菜单项却忘了配图标，那一刻是一个 `TypeError`。 ⚠️ 但**名字对不上**它拦不住（那会画出一个空方块，比漏掉更难发现）—— 守的是 `SiteMenuTests.test_every_entry_every_account_sees_carries_a_drawable_icon`， 它逐档账号地问「这个名字在这个文件里画得出来吗」。 ⚠️ 全部 `stroke="currentColor"` + `fill="none"`：面板底色有四档（浅 / 深无图 / 深有图 / 各自的模糊），任何一个写死的颜色都会在其中至少一档上看不清。 ⚠️ `aria-hidden` —— 每一项的名字由它旁边那行字给，读屏不该把图标也念一遍。 参数：icon —— 图标名。 {% endcomment %}
